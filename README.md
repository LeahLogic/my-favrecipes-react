# My Favorite Recipes

A responsive recipe search application built with React and TheMealDB API.

Discover delicious recipes from around the world, explore ingredients, and follow cooking instructions.

## ✨ Features

- Search recipes by name
- Search using the Enter key or search button
- Explore a variety of recipes on the homepage
- View recipe categories and cuisines
- Display ingredients and cooking instructions
- Expand and collapse recipe details
- Animated video background
- Responsive design
- Loading and no-results messages

## 🛠️ Technologies

- React
- Vite
- JavaScript
- HTML5
- CSS3
- TheMealDB API
- Google Fonts

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/LeahLogic/my-favrecipes-react.git
```

Install dependencies:

```bash
cd my-favrecipes-react
npm install
```

Start the development server:

```bash
npm run dev
```

## 📚 API

Recipe data is provided by [TheMealDB](https://www.themealdb.com/).
